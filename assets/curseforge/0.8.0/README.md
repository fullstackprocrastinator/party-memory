# Familiar Faces 0.8.0 media

Five branded demonstrations for the CurseForge gallery:

1. `01-journal.png` — continuous adventures, member roles and adventure notes.
2. `02-notes.png` — multiline notes, private nickname and shared history.
3. `03-role-filter.png` — the role selection menu.
4. `04-settings.png` — preferences and Remember my view.
5. `05-import.png` — a successful merge preview with duplicate and conflict counts.

The full images are 1160 pixels wide. The matching `description-800` images are 800 pixels wide for the description editor. Keep the explanatory footer visible.

These are demonstrations rendered from the actual addon Lua with fictional sample data. They are not screenshots from a running WoW client. Native game icons and input skins are represented by placeholders. No real player history or account data is included.

Reproduce using `scripts/create-080-previews.py` and `scripts/render-080-previews.cjs` (Python, Lupa, Pillow, Node, Playwright and Chromium required). The HTML layouts and converted wordmark are local rendering intermediates; upload the PNGs to the gallery.
