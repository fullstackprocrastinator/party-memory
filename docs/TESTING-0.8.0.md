# Familiar Faces 0.8.0 validation

Automated coverage: 53 Lua 5.1 tests pass, including existing party continuity, notes, recaps, tags, tooltip reminders and saved-data behaviour. New cases cover filter menus, view restoration and reset, multiline drafts, mouse-wheel paging, role history, a 3,000-adventure / 500-companion journal, safe import rejection, multipart input, merge conflicts, duplicate detection, ID remapping, replace mode and stale previews.

The five gallery images are generated by running the addon UI against deterministic mock APIs and fictional journal data. They demonstrate the Lua layout and button actions; native game icons and input skins are placeholders. They are not live game captures.

Before release testing in WoW Forever:

1. Close WoW, back up your account's `FamiliarFaces.lua` SavedVariables, and replace the addon folder with the 0.8.0 Forever package.
2. Enable script errors with `/console scriptErrors 1`, log in and open `/ff`. Confirm existing history and notes remain.
3. Select every new filter menu, including page two of a long tag menu. Check clearing filters and `/ff reset view`.
4. Choose Companions, a search and a sort. `/reload` and confirm the view returns. Switch off Remember my view and check a fresh login opens the default view.
5. Type a note with new lines and accented characters. Save it, reload and confirm the contents. Verify scrolling, cursor visibility, the counter and Save/Discard/Cancel.
6. Scroll over a multi-page journal and shared history. Verify page boundaries and that scrolling the note does not change journal pages.
7. Group with players whose roles the client supplies; inspect the recorded role, then a later adventure with a changed role. If the client supplies no role, verify Unknown without class-based guesses.
8. While solo, export the journal. Paste it into Import backup and preview a merge: duplicate adventures should be skipped. Confirm the merge and verify counts, notes and favourites.
9. Test multipart import and a deliberately incomplete backup on a disposable test journal. Invalid input must leave the existing journal unchanged.
10. Test Replace journal only with a recoverable test backup. Confirm the separate replacement step and preservation of settings. Imports during combat or in a party must be blocked.

Install ZIP inspection must confirm one root `FamiliarFaces` folder, interface 16001, version 0.8.0, and `Backup.lua` loaded immediately after `Store.lua`. Include only addon code, its bundled wordmark and license. Keep media and release documents out of the install ZIP.
